### <img src="https://img.shields.io/badge/-7aa2f7?style=flat-square&color=7aa2f7" width="4" height="20" /> &nbsp;Selected work

I build the layer that makes language models trustworthy: orchestration that verifies itself, retrieval you can measure, and guardrails that hold. Every project ships with a real eval harness, because "it felt better" is not a metric.
