## &nbsp;⟡&nbsp; About

I build AI systems that hold up in production, not just in the demo.

My work sits in the layer that makes language models trustworthy: multi-agent orchestration, retrieval you can measure, evaluation harnesses that catch regressions, and guardrails that stop bad outputs before a user ever sees them. Every project ships with a real eval harness, because "it felt better" is not a metric.

## &nbsp;⟡&nbsp; Featured Projects

#### &nbsp;🧩&nbsp; [multi-agent-orchestrator](https://github.com/rupeshpoojary9/multi-agent-orchestrator)
&nbsp;&nbsp;![stars](https://img.shields.io/github/stars/rupeshpoojary9/multi-agent-orchestrator?style=flat-square&color=7aa2f7&labelColor=1a1b27&logo=github) &nbsp;![last commit](https://img.shields.io/github/last-commit/rupeshpoojary9/multi-agent-orchestrator?style=flat-square&color=414868&labelColor=1a1b27) &nbsp;![lang](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)

&nbsp;&nbsp;A meta-agent plans a task DAG, routes steps to web and typed-API agents, runs a plan-verify-iterate loop, and synthesizes new sub-agents at runtime when a capability is missing.
&nbsp;&nbsp;**`100%` on a 26-task eval suite &nbsp;·&nbsp; `100%` verifier catch rate on injected failures.**

#### &nbsp;🔍&nbsp; [rag-eval-benchmark](https://github.com/rupeshpoojary9/rag-eval-benchmark)
&nbsp;&nbsp;![stars](https://img.shields.io/github/stars/rupeshpoojary9/rag-eval-benchmark?style=flat-square&color=7aa2f7&labelColor=1a1b27&logo=github) &nbsp;![last commit](https://img.shields.io/github/last-commit/rupeshpoojary9/rag-eval-benchmark?style=flat-square&color=414868&labelColor=1a1b27) &nbsp;![lang](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)

&nbsp;&nbsp;Reproducible retrieval benchmark: BM25 vs dense vs hybrid (RRF) vs hybrid + rerank over a hand-labelled corpus. Local models, no API key.
&nbsp;&nbsp;**Hybrid `recall@5 = 0.925` against a BM25 baseline of `0.738`.**

#### &nbsp;🛡️&nbsp; [bulwark](https://github.com/rupeshpoojary9/bulwark)
&nbsp;&nbsp;![stars](https://img.shields.io/github/stars/rupeshpoojary9/bulwark?style=flat-square&color=7aa2f7&labelColor=1a1b27&logo=github) &nbsp;![last commit](https://img.shields.io/github/last-commit/rupeshpoojary9/bulwark?style=flat-square&color=414868&labelColor=1a1b27) &nbsp;![lang](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)

&nbsp;&nbsp;Local-first LLM guardrails toolkit: layered PII, injection, secrets, and schema validators with a built-in eval harness.
&nbsp;&nbsp;**Stops unsafe inputs and outputs before they reach the model or the user.**

#### &nbsp;🧭&nbsp; [genai-refinement-advisor](https://github.com/rupeshpoojary9/genai-refinement-advisor)
&nbsp;&nbsp;![stars](https://img.shields.io/github/stars/rupeshpoojary9/genai-refinement-advisor?style=flat-square&color=7aa2f7&labelColor=1a1b27&logo=github) &nbsp;![last commit](https://img.shields.io/github/last-commit/rupeshpoojary9/genai-refinement-advisor?style=flat-square&color=414868&labelColor=1a1b27) &nbsp;![lang](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)

&nbsp;&nbsp;Recommends the cheapest refinement level (prompt vs RAG vs agent vs fine-tune) that clears a use case's quality bar, via cost-performance Pareto benchmarking.
&nbsp;&nbsp;**Turns "which approach do we even need" into a data-backed decision.**
