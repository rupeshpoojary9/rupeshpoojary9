## About

I build AI systems that hold up in production, not just in the demo.

My work sits in the layer that makes language models trustworthy: multi-agent orchestration, retrieval you can measure, evaluation harnesses that catch regressions, and guardrails that stop bad outputs before a user ever sees them. Every project ships with a real eval harness, because "it felt better" is not a metric.

- Focus: agentic orchestration, RAG retrieval quality, LLM evaluation and guardrails
- Primary stack: Python, FastAPI, LangChain, PyTorch

## Featured Projects

**[multi-agent-orchestrator](https://github.com/rupeshpoojary9/multi-agent-orchestrator)**
A meta-agent plans a task DAG, routes steps to web and typed-API agents, runs a plan-verify-iterate loop, and synthesizes new sub-agents at runtime when a capability is missing.
`100%` on a 26-task eval suite &nbsp;·&nbsp; `100%` verifier catch rate on injected failures.

**[rag-eval-benchmark](https://github.com/rupeshpoojary9/rag-eval-benchmark)**
Reproducible retrieval benchmark: BM25 vs dense vs hybrid (RRF) vs hybrid + rerank over a hand-labelled corpus. Local models, no API key.
Hybrid `recall@5 = 0.925` against a BM25 baseline of `0.738`.

**[bulwark](https://github.com/rupeshpoojary9/bulwark)**
Local-first LLM guardrails toolkit: layered PII, injection, secrets, and schema validators with a built-in eval harness.
Stops unsafe inputs and outputs before they reach the model or the user.

**[genai-refinement-advisor](https://github.com/rupeshpoojary9/genai-refinement-advisor)**
Recommends the cheapest refinement level (prompt vs RAG vs agent vs fine-tune) that clears a use case's quality bar, via cost-performance Pareto benchmarking.
Turns "which approach do we even need" into a data-backed decision.
