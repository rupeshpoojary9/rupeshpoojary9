### 🧠 About

I build AI systems that actually hold up in production, not just in the demo.

My focus is the unglamorous layer that makes LLMs trustworthy: multi-agent orchestration, retrieval that you can measure, evaluation harnesses that catch regressions, and guardrails that stop bad outputs before a user ever sees them.

- 🔭 Working on **agentic orchestration**, **RAG retrieval quality**, and **LLM evaluation & guardrails**
- 🧪 I ship every project with a real eval harness, because "it felt better" is not a metric
- ⚙️ Python-first, comfortable across the full LLM app stack: retrieval, agents, tooling, and infra
- 📫 Reach me at **poojary.rupesh12@gmail.com**

### 🚀 Featured Projects

| Project | What it does | Result that matters |
| :--- | :--- | :--- |
| [**multi-agent-orchestrator**](https://github.com/rupeshpoojary9/multi-agent-orchestrator) | A meta-agent plans a task DAG, routes steps to web and typed-API agents, runs a plan-verify-iterate loop, and synthesizes new sub-agents at runtime when a capability is missing. | **100%** on a 26-task eval suite, **100%** verifier catch rate on injected failures. |
| [**rag-eval-benchmark**](https://github.com/rupeshpoojary9/rag-eval-benchmark) | Reproducible retrieval benchmark: BM25 vs dense vs hybrid (RRF) vs hybrid + rerank over a hand-labelled corpus. Runs on local models, no API key. | Hybrid **recall@5 of 0.925** vs BM25 baseline **0.738**. |
| [**bulwark**](https://github.com/rupeshpoojary9/bulwark) | Local-first LLM guardrails toolkit: layered PII, injection, secrets, and schema validators with a built-in eval harness. | Catches unsafe inputs and outputs before they reach the model or the user. |
| [**genai-refinement-advisor**](https://github.com/rupeshpoojary9/genai-refinement-advisor) | Recommends the cheapest GenAI refinement level (prompt vs RAG vs agent vs fine-tune) that clears a use case's quality bar, via cost-performance Pareto benchmarking. | Turns "which approach do we even need" into a data-backed decision. |
